#Nome do Projeto: 
Recife ReaderDoc


#Problema Escolhido: 
Ineficiência e Erros na Extração Manual de Dados de Documentos 

#Site Utilizado: 
https://bancodeoportunidades.recife.pe.gov.br/

#Proposta de intervenção: 
A solução do problema foi desenvolvida com base em questões de acessibilidade e variabilidade para formatos suportados.

A UI do site segue princípios minimalistas para poder evitar um possível acúmulo de poluição visual e inacessibilidade das ferramentas, a forma que foi desenvolvida garante o entendimento rápido das funções fornecidas pela ferramenta. A plataforma também visa codificar uma automatização na hora da leitura e transformação de documentos para o formato desejado, dessa forma a porcentagem de validação correta será aumentada de forma que garanta o mais próximo possível de 100%.

#Instruções de execução

1. entre em uma pasta vazia e faça um git clone https://github.com/arthurvfbarros-blip/recife-readerdoc.git

2. entre na pasta do projeto: cd recife-readerdoc/

3. no terminal digite npm start e aguarde o início da aplicação
